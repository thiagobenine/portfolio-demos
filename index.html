Seven landing pages, each with its own visual world.

Designed and coded by Thiago as portfolio demos, most of them for the kind of work he does: payments for Brazil, API load testing, web data, app integrations and logs and monitoring, plus a coffee subscription and a time-tracking tool. Every page is responsive and hand-built in HTML, CSS and JavaScript. The brands are fictional.

  1. Cobogó

    Payments API for Brazil

    Drawn like a São Paulo metro map. A PIX payment rides a yellow line through four stations, from QR shown to order paid, and PIX, boleto and cards meet at one interchange. The QR code only decodes to a demo notice.

    Open the page

  2. Proofload

    Load testing for APIs

    Styled on the rated capacity plate and proof-load tag of lifting gear. The first screen reads like the cover of an engineering test report: rated load, proof load at three times the real peak and a punched verdict tag. A calculator re-stamps every rating from the visitor's own peak.

    Open the page

  3. Rowcrop

    Web data, done for you

    A continuous-form computer printout. The first screen is the data table itself: rows print in, duplicates are struck through and a changed price is lifted in red with the old value kept.

    Open the page

  4. Bothways

    App integrations built as code

    A restaurant ticket rail. Every sync arrives as a numbered ticket; switch the accounting app off and the orders wait, retry and go through in order once it is back.

    Open the page

  5. Tamis

    Logs and monitoring setup

    Air traffic control flight strips on a cobalt board. The page opens on raw logs where every line says ERROR, then sorts once: unexpected errors pushed out of line in red, expected ones counted and left alone.

    Open the page

  6. Hourcard

    Time tracking for studios

    A Swiss object poster built around one stopwatch. The headline splits above and below the dial, and closing the demo week turns the running timer into client arcs with their invoice totals.

    Open the page

  7. Rest Days

    Coffee subscription

    The first screen is a poster-sized chart of the gas leaving freshly roasted beans, day by day. Roasted Monday sits at day zero, ready by Saturday hangs from day five, and one red means gas still in the beans across the whole page.

    Open the page
